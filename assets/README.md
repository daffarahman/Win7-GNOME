# Windows 7 Start orb

`win7-start-orb.png` is the 128 × 128 full-color Windows orb from
[B00merang-Artwork/Windows-7](https://github.com/B00merang-Artwork/Windows-7),
at commit `b1577ced806262ae0caad89ed183d1d5b0336852`:

[Original PNG](https://github.com/B00merang-Artwork/Windows-7/blob/b1577ced806262ae0caad89ed183d1d5b0336852/extras/start-here/win2-7.png).

The original artwork is retained without modification. The builder downsamples
it to each supported size up to 128 pixels, without upscaling it.

It is installed as `view-app-grid-user-symbolic.png`, the session-specific name
requested by Dash to Dock for Show Applications. The plain PNG extension keeps
its full colors. No shared app-grid, toolbar, status, or login-screen icons are
replaced. Clicking the orb continues to open GNOME's application grid.
