# Artwork credits

The Windows 7 Start orb is from **b00merang / B00merang Artwork**:
[B00merang-Artwork/Windows-7](https://github.com/B00merang-Artwork/Windows-7).
The pinned source image and its use are documented in [assets/README.md](https://github.com/daffarahman/Win7-GNOME/blob/main/assets/README.md).

The application, folder, drive, and Recycle Bin artwork comes from the supplied
Windows 7 Build 7600 icon collection, extracted from Windows resources. The
selected original ICO files are included under `artwork/`; `icons.json` maps
every design to its original resource path. These Windows icons are Microsoft
artwork. The b00merang credit applies to the separately sourced Start orb.

This project provides GNOME naming, aliases, conversion, installation, and
Adwaita fallback. Original artwork remains credited to its respective owners;
this adaptation does not grant a new license to that artwork. WhiteSur's naming
and directory organization served as an initial compatibility reference.
